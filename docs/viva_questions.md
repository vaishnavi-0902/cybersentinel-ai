# Viva Questions and Answers

### Q1: What is CyberSentinel AI?
A: It is a defensive cyber monitoring platform that analyzes event data and predicts suspicious activity.

### Q2: Why use machine learning?
A: It helps identify patterns and anomalies that are difficult to detect manually.

### Q3: What is Random Forest?
A: An ensemble of decision trees used for classification tasks.

### Q4: What is Isolation Forest?
A: A tree-based anomaly detector that isolates unusual observations.

### Q5: What is FastAPI?
A: A modern Python web framework used for APIs.

### Q6: What is Streamlit?
A: A Python library for building dashboards quickly.

### Q7: Why use PostgreSQL?
A: It stores structured logs, users, and alerts reliably.

### Q8: What is Docker?
A: A tool for packaging applications into containers.

### Q9: What is Kubernetes?
A: A platform for container orchestration and scaling.

### Q10: What is Jenkins?
A: A continuous integration tool used for automation.

### Q11: What is JWT?
A: A token-based authentication mechanism.

### Q12: What is risk scoring?
A: It assigns a number from 0 to 100 based on suspicious conditions and model output.

### Q13: Why log events?
A: Logs help investigate and audit abnormal behavior.

### Q14: What is a false positive?
A: A normal event classified as suspicious.

### Q15: What is a false negative?
A: A suspicious event classified as normal.

### Q16: What is precision?
A: Of all predicted suspicious events, how many were truly suspicious.

### Q17: What is recall?
A: Of all true suspicious events, how many were detected.

### Q18: What is F1-score?
A: A balanced metric combining precision and recall.

### Q19: What is CI/CD?
A: Continuous integration and continuous deployment.

### Q20: What is HPA?
A: Horizontal Pod Autoscaler that adjusts pod count based on load.

### Q21: What is the CIA triad?
A: Confidentiality, Integrity, and Availability.

### Q22: Why is input validation important?
A: It prevents invalid or maliciously shaped requests from harming the system.

### Q23: What is a Pod?
A: A smallest deployable unit in Kubernetes.

### Q24: What is a Service?
A: An abstraction that exposes pods internally or externally.

### Q25: Why do we not use real attacks in a student project?
A: Because the project must remain safe and ethical.

### Q26: What is anomaly detection useful for?
A: Finding rare or unusual patterns in security data.

### Q27: What is a dataset label?
A: A target value used during supervised learning.

### Q28: What is feature engineering?
A: The process of creating useful inputs for machine learning.

### Q29: What is a confusion matrix?
A: A table showing true and false classifications.

### Q30: Why use simulated data?
A: It is safe and accessible for academic learning.

### Q31: What is a security event?
A: A record of user or system activity relevant to monitoring.

### Q32: What is the role of a risk engine?
A: To combine model and rule outputs into a final score.

### Q33: Why do we need alerts?
A: To notify analysts about critical activity quickly.

### Q34: What is a dashboard used for?
A: To monitor and communicate security insights.

### Q35: What is an API?
A: A way for systems to communicate with each other.

### Q36: What is a deployment manifest?
A: A YAML file that describes Kubernetes resources.

### Q37: What is a service mesh?
A: A network layer for service-to-service communication in advanced architectures.

### Q38: Why is automated testing important?
A: It catches regressions early and builds confidence.

### Q39: What is the difference between classification and anomaly detection?
A: Classification learns from labels; anomaly detection looks for outliers without labels.

### Q40: Why do we need threat scoring transparency?
A: It helps analysts understand and trust the reason behind alerts.

### Q41: What is the purpose of a model metadata file?
A: It stores metrics and information about a trained model.

### Q42: What is status code 401?
A: Unauthorized access.

### Q43: What is status code 400?
A: Bad request.

### Q44: What is status code 500?
A: Internal server error.

### Q45: Why is secure coding important in cybersecurity?
A: Because security tools must protect systems instead of exposing them.

### Q46: What is the role of logs in incident response?
A: Logs provide evidence and event history for investigation.

### Q47: What is the purpose of risk severity levels?
A: To classify the urgency of an alert.

### Q48: What is a critical alert?
A: A severe event that requires immediate attention.

### Q49: Why do we use environment variables?
A: To keep secrets and configuration separate from code.

### Q50: How can future versions improve this system?
A: By adding real-time model retraining, SIEM integration, and more advanced dashboards.
